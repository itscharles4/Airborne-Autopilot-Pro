About the Project

Built from First Principles

Airborne Autopilot Pro started as a question: can a single web platform replace an entire operations room? Two semesters later — the answer is yes.

  • Full-stack architecture spanning React frontend to Docker-containerised microservices
  • Classical algorithms (Dijkstra, TSP) implemented from scratch with academic rigour
  • AI integration that grounds Gemini in live operational data — not hypotheticals
  • Real-time collision detection running every 3 seconds with automatic rerouting
  • Revenue analytics backed by MongoDB aggregation pipelines, not client-side math
  • Designed for scalability: Redis pub/sub supports multi-instance horizontal deployment
