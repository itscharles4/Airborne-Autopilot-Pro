02

Pathfinding Engine

Dijkstra + TSP
Routing Core

The heart of every flight plan. Dijkstra's algorithm runs O((V+E)logV) using a custom MinHeap across a 20-node city graph. Results are Redis-cached for 5 minutes.

Single-Path (Dijkstra)
Point A to Point B — optimal route guaranteed. No-fly zones respected on every call. Computes in under 50ms.
Multi-Stop (TSP Heuristic)
Nearest-Neighbour for large inputs. Auto-upgrades to brute-force for ≤ 8 stops — guarantees the optimal tour.
Live No-Fly Zones
Admin API updates the active NoFlyZones Set in real time. Next Dijkstra call routes around them instantly.
Redis Path Cache
Computed paths cached 5 min by start:end:avoid key. Identical requests served from cache in < 1ms.

System Architecture

Built for Scale
& Security

Five clean tiers — Presentation, API, Service, AI, and Data — each communicating over well-defined interfaces with JWT auth, rate limiting, and TLS 1.3 in production.
